# Harbor Link

A decentralized endpoint application for financial services providers to enable discovery and financial transactions using open protocols.

## Overview

Harbor Link is a modern, decentralized platform designed to facilitate financial services discovery and transactions. It leverages open protocols such as ONDC (Open Network for Digital Commerce) and OCEN (Open Credit Enablement Network) to create a seamless, interoperable financial ecosystem.

## Key Features

- **Decentralized Architecture**: Built on open protocols for secure and transparent financial transactions
- **Protocol Support**: Integrates with ONDC, OCEN, and other emerging open financial protocols
- **Service Discovery**: Enables financial service providers to be discovered by potential customers
- **Transaction Processing**: Facilitates secure financial transactions through standardized protocols
- **Interoperability**: Designed to work with multiple financial service providers and protocols

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/saurabh-karn/harbor-link.git

# Install dependencies
cd harbor-link
npm install

# Start the development server
npm run dev
```
